# Zerodha Full Stack Project 📈

This is a beginner-friendly **full stack web application** inspired by the Zerodha trading platform.  
I am building this project to practice **full stack development** and understand how frontend and backend work together.

---

## 🚀 Tech Stack Used

**Frontend**
- React.js
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB (planned / learning phase)

---

## ✨ Features (Current & Planned)

- User Interface inspired by Zerodha
- Responsive frontend design
- Backend API integration (in progress)
- User authentication (planned)
- Dashboard and data handling (planned)

---

## 📂 Project Status

🚧 **Work in Progress**

This project is being developed step by step as part of my learning journey.  
New features and improvements will be added regularly.

## ▶️ How to Run the Project (Basic)

# clone the repository
git clone https://github.com/Tiyatiwari/Zerodha_fullstack_project.git

# go to project directory
cd Zerodha_fullstack_project

# install dependencies
npm install

# start the project
npm start
